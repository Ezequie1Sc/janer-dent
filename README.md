# JANERDent

Sitio web oficial de **JANERDent**, consultorio dental ubicado en Hecelchakán, Campeche.

El proyecto presenta de forma clara y moderna los servicios odontológicos del consultorio, información sobre la clínica y diferentes medios para facilitar el contacto con los pacientes.

## Sobre el proyecto

JANERDent es una landing page desarrollada para ofrecer a los pacientes una experiencia sencilla, moderna y adaptable a cualquier dispositivo.

El sitio permite conocer:

- Información del consultorio.
- Servicios y tratamientos dentales.
- Beneficios de atenderse en JANERDent.
- Galería de imágenes.
- Información sobre la clínica.
- Ubicación del consultorio.
- Formas de contacto.
- Acceso directo a WhatsApp.

## Tecnologías

El proyecto está desarrollado utilizando:

- **Angular**
- **TypeScript**
- **SCSS**
- **Tailwind CSS**
- **HTML5**
- **Vercel**

## Características

### Diseño responsive

La interfaz está diseñada para adaptarse a:

- Computadoras de escritorio.
- Tablets.
- Teléfonos móviles.

### Servicios odontológicos

El sitio presenta los principales tratamientos y servicios ofrecidos por el consultorio mediante una interfaz visual y accesible.

### Galería

Incluye una sección visual para mostrar las instalaciones y contenido relacionado con los servicios de JANERDent.

### Ubicación

Los pacientes pueden consultar fácilmente la ubicación del consultorio mediante Google Maps.

### Contacto

Se incluye un botón de contacto directo mediante WhatsApp para facilitar la comunicación con el consultorio.
